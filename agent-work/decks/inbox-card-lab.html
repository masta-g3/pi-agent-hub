Seven decisions

Display-only variants. Producer text, order, original option indices and answer payloads stay intact unless an exception is explicitly called out.

E1 Where the card begins and ends

Recommend A · frame the selected request card.

Gestalt enclosure gives identity, question and action one owner. Leave unselected neighbors quiet; do not frame every fleet row.

Preserves D1 in-place expansion and one shared shell. Proposed refinement to D2: selected-card group moves from its metadata line into the top edge at widths where it fits; never show it twice. Worktree marker remains after the title. This is not a new dashboard outer frame.

E2 Ask first; fold only the context

Recommend A · ask-first, structured conditions, context one key away.

Progressive disclosure removes background, not the decision’s conditions. Do not make a long request look simpler by hiding a qualification.

Display rule, not a summary

Use the final sentence ending in ?, including its inline list, as the lead. Split literal (1) … (2) … markers into rows. Preserve their order and text. Fold the rest under Context; no inferred facts, title rewrite or answer mutation.

For this fixture, the lead is still long. It must scroll, not elide. The dry-run promise after the question is safety-relevant context, not a numbered completion criterion: A folds it, and the expanded specimen shows it in full. If review requires that promise always visible, choose B rather than silently hiding an approval condition.

Conservative fallback

If no ? exists, sentence boundaries are ambiguous (code, a URL query, quoted questions), or moving text would detach a condition, show the text as written. Do not run a language model. O Original toggles the raw, full text with the same options and selection.

Proposed D4 refinement: add local C Context and O Original only in answer focus, outside literal text editing. These uppercase keys are unbound in the current catalog. Keep x Close pin, y Copy path and i Details unchanged. Local C/O never replace global keys in fleet focus.
